## ✅ Checklist: Próximos Pasos

### Preparar el Proyecto
- [ ] Copia los archivos de fuente (`src/`, `qa/`, `build.py`) a esta carpeta
- [ ] Copia `arranca-del-aluvion.html` (archivo compilado)
- [ ] Inicializa Git: `git init`

### Publicar en GitHub
- [ ] Lee [GITHUB_SETUP.md](GITHUB_SETUP.md)
- [ ] Crea repositorio en github.com/new
- [ ] Ejecuta: `git add . && git commit -m "Initial commit" && git push`
- [ ] Habilita GitHub Pages (Settings → Pages)
- [ ] Añade topics (three-js, game, webgl, etc.)

### Compartir el Juego
- [ ] Comparte en Twitter/X
- [ ] Comparte en Reddit (r/gamedev, r/webgames)
- [ ] Comparte en LinkedIn
- [ ] Publica en itch.io también
